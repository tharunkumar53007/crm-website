# CRM Dashboard

A full-stack CRM website built with Next.js, TypeScript, and a lightweight in-memory API layer.

## Features
- Sales dashboard with key performance metrics
- Leads and customers overview
- Deal pipeline tracking
- Task management
- Activity feed
- Contact creation API
- Deal status updates

## Stack
- Frontend: Next.js 14 + React + TypeScript
- Styling: CSS modules / global CSS
- Backend: Next API routes
- Persistence: in-memory data store for demo purposes

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```
